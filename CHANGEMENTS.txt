==============================================================
CORRECTIF SPLASH — AFYA APP (CRF-MK) — 02/11/2026
==============================================================

LE PROBLEME
-----------
L'écran d'entrée (splash CRF-MK) s'affichait à CHAQUE changement de
page et après chaque action, alors qu'il ne doit apparaître qu'au
lancement de l'app ou quand on actualise (F5).

LA CORRECTION (templates/base.html uniquement)
----------------------------------------------
Le splash s'affiche maintenant UNIQUEMENT :
- à l'ouverture de l'app (nouvel onglet, lancement sur mobile) ;
- à une actualisation de la page (F5 / tirer-pour-rafraîchir).
Il ne s'affiche PLUS :
- quand on navigue entre les pages (menu, liens) ;
- après une action (enregistrement, validation -> redirection) ;
- avec les boutons précédent/suivant du navigateur.

INSTALLATION
------------
1. Extraire ce zip à la racine du projet (remplace templates/base.html).
2. En local : git add templates/base.html && git commit && git push
3. Sur le serveur :
       cd /var/www/afya-app && git pull
       sudo systemctl restart afya
   (pas de migration, pas de pip install — juste le template)

NOTE : les pages « Assistant » et « Rapports » qui affichent une
erreur 500 sont un problème SÉPARÉ, en cours de diagnostic — la trace
exacte du serveur (journalctl) permettra de le corriger.
